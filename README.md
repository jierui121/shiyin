# 拾音

**把录音整理成可编辑的文字与笔记。**

拾音是一款 Windows 桌面应用，支持现场录音、导入音频、本地语音转写和 AI 纪要。无需安装 Python，解压即可使用；随包内置 small 模型，可离线完成语音转写。

[下载 Windows x64 免安装版](https://github.com/jierui121/shiyin/releases/latest) · [使用说明](#开始使用) · [反馈问题](https://github.com/jierui121/shiyin/issues)

## 你可以用它做什么

- **记录现场声音**：录音支持暂停与继续，实时显示波形，停止后选择保存位置。
- **整理已有录音**：导入 WAV、MP3、M4A、AAC、FLAC、OGG、OPUS 等常见音频，保留导入源文件。
- **离线转成文字**：使用 faster-whisper 在本机转写，支持选择不同规模的模型，中文文本统一为简体。
- **按需要生成纪要**：连接兼容 OpenAI 的 API，选择日常记录、会议纪要或自定义要求。
- **边听边改笔记**：拖动进度条定位播放，原文与纪要并排查看，编辑后自动保存。
- **按日期管理录音**：通过日历查找、调整归属日期、打开文件夹，或删除不需要的录音及笔记。

## 下载与运行

1. 打开 [最新版本](https://github.com/jierui121/shiyin/releases/latest)，下载 **Shiyin-Windows-x64.zip**。不要下载页面自动生成的 Source code，那是开发用的源码。
2. 完整解压 ZIP，进入解压后的应用文件夹。
3. 双击 **Shiyin.exe**。

运行时请保留同目录的 `_internal` 和 `models` 文件夹。移动应用时，请一起移动整个应用文件夹。

适用平台：**Windows x64**。默认使用 CPU 转写，无需配置 CUDA。内置 small 模型；改用其他模型时，首次需要联网下载，之后可离线使用。更大的模型需要更多内存和处理时间。

发行页提供 `SHA256SUMS.txt`，可用于核对下载文件：

```powershell
Get-FileHash .\Shiyin-Windows-x64.zip -Algorithm SHA256
```

## 开始使用

### 录制或导入

在“设置”中选择默认存储路径与本地转写模型，点击“保存设置”。

回到录制页，选择录音归属日期，然后开始录音，或点击“导入录音”选择已有音频。现场录音可以暂停、继续；停止后为录音选择名称和保存位置，保存完成后自动转写。取消保存会丢弃本次录音。

导入音频会转换为 MP3 并加入笔记库，原文件保持不变。新保存的笔记包含：

| 文件 | 内容 |
| --- | --- |
| `audio.mp3` | 录音 |
| `transcript.txt` | 转写原文 |
| `summary.md` | AI 纪要（生成后） |

### 查看与编辑

在笔记库中通过日历选择日期，再从列表中选择录音。原文与纪要可直接编辑，编辑后自动保存，界面会显示保存状态。

拖动播放进度条可定位到想听的位置。需要重新处理时：

- **重新转写**：使用当前本地模型更新原文，保留已有纪要。
- **重新生成纪要**：使用当前原文和纪要设置更新纪要，保留原文。可以先修订识别结果，再生成纪要。

“修改日期”调整录音的归属日期；“删除录音”经确认后删除该条录音、原文和纪要。删除不会移除导入源文件。

### 配置 AI 纪要

本地录音和转写不需要 API Key。若需要 AI 纪要：

1. 在“设置”中填写服务商的 API Base URL、API Key 和模型名称。
2. 点击“保存设置”，再验证连接。
3. 选择“日常记录”“会议纪要”或“自定义”风格。自定义要求最多 1000 字，修改后记得保存。
4. 录音或导入前勾选“本次录音 / 导入生成 AI 纪要”，或在笔记库中点击“重新生成纪要”。

支持兼容 OpenAI 的接口，并适配 DeepSeek 官方接口。API 费用由所选服务商收取，连接验证也会产生一次少量调用。转写准确度和纪要内容会受音频、模型及提示要求影响，使用前可在笔记库中检查、修订。

## 数据与隐私

音频在本机转写。启用 AI 纪要时，转写原文会发送给你配置的 API 服务商；音频文件不会随纪要请求上传。

发行版的数据目录为：

| 路径 | 用途 |
| --- | --- |
| `%LOCALAPPDATA%\Shiyin\data` | 设置、API 验证记录、录音索引与日志 |
| `%LOCALAPPDATA%\Shiyin\data\recordings` | 首次使用时的默认录音目录，可在设置中更改 |
| `%LOCALAPPDATA%\Shiyin\models` | 额外下载的转写模型 |

API Key 使用 Windows DPAPI 加密，绑定当前 Windows 用户。音频、原文与纪要以普通文件保存。备份时，请同时保留数据目录和你实际选择的录音存储目录；不要手动移动已经加入笔记库的录音文件夹。

更新应用时，关闭软件后将新版解压到新文件夹运行即可；设置和笔记库保存在应用文件夹之外。

## 常见问题

**下载后为什么打不开？**

请先完整解压，再运行 `Shiyin.exe`，并检查 `_internal`、`models` 是否与 EXE 在一起。启动错误可查看 `%LOCALAPPDATA%\Shiyin\data\startup.log`。

**模型下载失败怎么办？**

软件会尝试官方与备用下载通道，并保留已下载的进度。恢复网络后重新转写即可；也可选择随包内置的 small 模型。

**能只转写、不生成纪要吗？**

可以。不配置 API 或不勾选纪要开关，即可只进行本地转写。已有录音也可以单独重新转写。

**生成纪要失败后需要重录吗？**

不需要。音频和已有原文会保留，检查 API 配置与网络后，在笔记库中重新生成纪要即可。

**怎样反馈问题？**

请在 [Issues](https://github.com/jierui121/shiyin/issues) 中描述操作步骤、提示信息和 Windows 环境。附日志前请检查其中是否包含不希望公开的路径或内容，不要提交 API Key、个人录音与笔记。

## 使用的开源组件

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)：本地语音转写
- [PyAV](https://github.com/PyAV-Org/PyAV)：音频转换与读取
- [python-sounddevice](https://github.com/spatialaudio/python-sounddevice)：音频录制
- [OpenCC Python](https://github.com/yichen0831/opencc-python)：繁简转换

第三方组件与模型遵循各自的许可证。

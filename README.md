# 拾音 · 本地录音笔记

[下载 Windows 免安装版](https://github.com/jierui121/shiyin/releases/latest) · [源码仓库](https://github.com/jierui121/shiyin)

这是 Windows 桌面应用，下载发行包后在本机运行。GitHub 提供源码和安装包分发。

Windows 桌面软件。最新免安装应用版在 `release/Shiyin-1.3/Shiyin.exe`，双击即可运行，无需 Python。完整分享包为 `release/Shiyin-Windows-x64.zip`，解压整个文件夹后运行 EXE，请保留同目录 `_internal` 与 `models`。源码版仍可双击 `start.bat` 启动。

当前机器项目根目录提供 `AI录音笔记.lnk`，可重命名此快捷方式而不影响启动。快捷方式应指向最新正式发行应用；`build` 目录中的 EXE 是构建中间文件，没有完整运行依赖。若重命名或移动正式 EXE，需要同步更新快捷方式目标；移动应用时须一起移动整个应用文件夹。

应用版的设置、验证状态、索引和日志保存在 `%LOCALAPPDATA%/Shiyin/data`，默认录音也保存在该用户目录下；已经配置的存储路径保持有效。源码版仍使用项目的 `data`。程序与用户数据分离，更新程序不覆盖设置。当前机器已有设置已迁移到应用版用户目录，发行压缩包中不包含任何个人密钥、录音或笔记。

免安装包已内置 small 模型；选择其他规模的模型首次需要联网下载。程序先查找随包模型及用户缓存；首次下载优先连接 Hugging Face，失败后尝试 hf-mirror.com。界面显示文件名、百分比与已下载大小，支持保留 .part 文件断点续传，下载完成按 SHA256/Git blob 校验后才启用。应用版额外模型缓存位于 `%LOCALAPPDATA%/Shiyin/models`，更新程序不会重新下载。当前机器的 medium 已准备好；分享包只内置 small。需要重建时，在项目虚拟环境安装 `requirements-build.txt` 后运行 `build.ps1`。

启动异常会弹出中文提示，详细错误记录在 `data/startup.log`。`start.bat` 必须保持 UTF-8 无 BOM、Windows CRLF 换行，避免 cmd 截断命令。

## 使用

笔记库选择一条录音后，点击“删除录音”，确认后永久删除该条音频、原文和纪要并移除索引。删除前停止该条录音的播放，删除最后一条时清空预览。正在处理的录音不能删除。索引写入失败会还原文件；目录内自行添加的其他文件、导入源文件和其他笔记保留。

窗口右上角显示“就绪 / 录制中 / 录音已暂停 / 处理中”。导入音频、保存 MP3、转写和生成纪要属于“处理中”。现场录音期间（包括暂停）关闭窗口会询问是否丢弃本次录音；取消则继续保留录音，确认则关闭麦克风、删除本次尚未保存的临时录音并退出。后台处理期间退出会单独提示等待处理完成。

录音预览区新增可拖动播放进度条：播放中向前或向后拖动，松开后从对应位置继续；未播放时也可拖动定位后播放。新录音与导入录音统一保存为 `audio.mp3`（16kHz、单声道、64kbps）。录制期间临时写入 WAV 以便异常恢复，保存后后台转换为 MP3 并删除临时 WAV。历史 WAV 仍可读取。

录制页现支持“导入录音”：先选择录音归属日期，需要纪要时勾选“本次录音 / 导入生成 AI 纪要”，再选择本地音频。支持 WAV、MP3、M4A、AAC、FLAC、OGG、OPUS 等常见格式（具体取决于音频编码）。程序在后台转换为 16kHz 单声道 MP3，按源文件名建立笔记文件夹，重名自动编号，然后自动生成原文和可选纪要；源文件保持不变。导入记录可在笔记库播放、编辑、重新转写和生成纪要，详情显示导入时间。转换失败会提示错误并清理本次临时输出；转写或纪要失败后仍保留已导入音频，可重试。转换和转写期间请等待处理完成后退出。

1. 设置中选择默认存储路径和转写规模，并点击“保存设置”。转写后端固定为 faster-whisper，规模仅能从 tiny、base、small、medium、large-v3 列表选择，默认 small，不支持自定义模型目录。更大模型需要更多内存和处理时间。
2. 点击开始录音，可以暂停、继续；停止后弹出系统保存对话框。所选 MP3 名称作为文件夹名称，文件夹中固定保存 `audio.mp3`、`transcript.txt`、`summary.md`。点击取消会丢弃本次录音，不保存文件、不转写。重名文件夹自动编号。录制波形已放大，开始和结束时均清零；仅放大显示，不改变音频音量。
3. 在笔记库点击“日历选日期”，可以翻月选择日期，带 ● 的日期有录音；也可输入日期查找。顶部下拉列表默认选中当天第一条，显示时间、标题和时长，支持切换、播放、停止和打开目录。播放时显示随音频位置变化的波形与时长，停止、切换录音或播放结束后清零。纪要在左，默认占约四分之一宽度；原文在右，占约四分之三，左右同时显示，可拖动分隔条调整宽度。
4. 如需纪要，填写兼容 OpenAI 的 API Base URL（通常以 `/v1` 结尾）、Key，获取或手动填写纪要模型，保存设置后点击验证。获取模型不会自动保存设置。按钮在验证期间显示“正在验证”，下方持续显示成功、失败原因和上次成功时间。成功状态会保存，API 地址、密钥、模型不变时，重启软件或更新代码后无需重复验证；修改纪要风格、原文模型或存储路径不影响 API 验证。更换 API 配置或后续纪要请求失败时需重新验证。验证会产生一次少量 API 调用；历史成功记录不代表远端服务始终在线。
5. AI 纪要风格可选“日常记录”“会议纪要”“自定义”。日常记录使用少量文字概括为一段，不分点、不加标题；会议纪要保留升级前已保存的要求，新安装默认整理主题、核心要点、结论与待办。只有自定义模式可编辑“纪要要求”（最多 1000 字），切换预设再切回自定义会保留本次草稿。风格与其他设置一样，保存后生效，未保存离开设置页则丢弃。
6. 录音完成后自动执行一次本地转写。笔记库的“重新生成纪要”只使用当前原文（包括手动修订），不重新转写、不修改原文；使用当前已保存的纪要风格和 API 设置，独立于录制页的本次纪要开关，API 需已验证。
7. 所有设置只有点击“保存设置”后才生效；未保存就离开设置页，草稿会清除，恢复为上次保存的值。选择存储路径也遵循此规则。

录制页可通过日历设置“录音归属日期”，启动时默认为当天，也可点击“今天”恢复。保存时录音按所选日期归类。笔记库选中录音后点击“修改日期”，选定新日期即保存并切换到该日、保持选中当前录音。修改仅更新日期索引，不移动文件夹，也不修改实际录制时间；详情会同时显示两者。纪要开关选中时显示白色勾号，未通过 API 验证时仍不可开启。

笔记库的纪要与原文可直接编辑，停止输入约 250ms 后自动覆盖对应的 `summary.md` / `transcript.txt`，不创建备份。文本框下方显示“正在自动保存”“已自动保存”或失败提示；切换录音、失去编辑焦点、重新处理和退出前立即补存最后一次修改。写入失败时保留旧文件与编辑框中的修改，阻止切换录音或退出，避免丢失内容。

预览区提供两个独立按钮：“重新转写”根据 `audio.mp3`（兼容旧版 `audio.wav`） 和当前已保存的本地模型更新 `transcript.txt`，不调用 LLM、不修改已有纪要、不要求 API 已验证；“重新生成纪要”先保存手动修订的当前原文，再调用 LLM，成功后只覆盖 `summary.md`，不重新转写。处理期间禁止重复点击并暂时锁定目标录音的编辑，其他录音仍可编辑。原文为空或缺失时不发起 API 请求；纪要生成失败保留旧纪要。状态行持续显示下载、转写、生成纪要和完成/失败反馈。

转写文本在写入文件前使用本地 OpenCC 繁转简，纪要同样统一为简体。已有原文与纪要在预览时也会转换为简体；旧文件本身不会自动覆盖，手动编辑后自动保存。英文、数字与时间戳保留。转换使用 [OpenCC 的 Python 实现](https://github.com/yichen0831/opencc-python)，无需联网。

DeepSeek 官方接口（`https://api.deepseek.com` 或其 `/v1` 路径）已适配：验证与纪要请求默认关闭思考模式，避免输出额度被思考过程耗尽；验证仅检查连接，不附带纪要要求。其他服务不会收到 DeepSeek 专用参数。输出被长度限制截断时，程序最多自动增加额度重试一次；仍未完成会明确报错，不会把思考过程或截断正文保存为成功纪要。当前纪要初始输出额度为 8192 tokens，重试上限为 16384，实际费用依服务商计费。

录制与播放波形以 30 FPS 刷新，显示最多 320 根彼此有间隙的独立竖线，保持 2px 线宽，不使用连续填充波纹。窗口变窄时自动减少线条数量，保持可见间隙。底层每 10ms 提取 RMS/峰值混合包络，保留对数幅度细节与约 6.4 秒的历史；相比原先的 3.2 秒时间窗，同一段声音的横向移动速度减半，不改变录音或播放速度。

竖线分组固定在音频的绝对时间轴上：历史竖线保持高度，随时间向左移动。横向使用统一的整数像素间距，所有竖线共享同一个整数滚动偏移，避免小数坐标取整产生漂移的宽窄间隙。波形有效区域居中，边缘保留不足一个完整网格所需的余量。

音频始终在本机转写，只有开启纪要时才会将转写原文发送到配置的 API。API Key 使用 Windows DPAPI 加密，绑定当前 Windows 用户；本机音频、原文和纪要文件为普通文件。

## 本地文件

- `data/settings.json`：设置和加密密钥。
- `data/api_verification.json`：上次验证成功时间和 API 配置指纹，不包含明文密钥。保留 data 目录即可在重启和更新程序后恢复验证状态。
- `data/library.json`：跨存储目录的录音索引，修改默认路径不会丢失旧记录。
- `data/recordings/`：默认录音路径。
- `data/pending-*.wav`：录音中的临时音频或保存失败时的恢复文件；确认不需要后可手动删除。
- `data/app.log`：错误与转写进度，不记录 API Key 或请求正文。
- `models/`：自动下载的模型缓存。首次下载需要访问 Hugging Face；下载完成后本地转写无需网络。

不要手动移动已索引的文件夹。录音期间持续写入磁盘，暂停不计时；处理期间请等待完成再退出。程序异常中断时，pending WAV 可能需要修复文件头后恢复。

## 重新安装环境

仅在本项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.bat
```

默认使用 CPU int8 转写，无需 CUDA。模型说明见 [faster-whisper 官方项目](https://github.com/SYSTRAN/faster-whisper)。
